    App installieren

    Info

    ShakeyMakey speichert Klassen, Namen und Verlauf dauerhaft in SQLite auf dem Server. Deine Einstellungen (Klasse, Aufteilung, Anzahl) merkt sich nur dieses Gerät.

    Optional lässt sich alles auch per Telegram-Bot steuern (Befehl /menu mit Buttons, Startmeldung beim Containerstart). Einrichtung und Variablen: siehe README im Repository.
